# Support

This is a free, community project maintained on a **best‑effort** basis.
There are **no formal SLAs**, no guaranteed response times, and no private/email support.

## How to get help

- **Questions / Bugs / Feature requests:** please open a **GitHub Issue** on the repository.
- Before filing an issue:
  - Search existing issues (open and closed).
  - Make sure you’re on the **latest release**.
  - Check the `README.md` and the docs in the `docs/` folder.

## What to include in a bug report

- Version (from `pyproject.toml` or the `--version` output)
- OS and Python version
- Exact steps to reproduce (minimal example is best)
- Expected vs. actual behavior
- Relevant logs (redact any secrets)
- Small, sanitized sample files (e.g., `.srt`) if applicable

## Feature requests

Describe the problem you’re trying to solve and the workflow. Pull requests are welcome!

## Security

Please **do not** file public issues for potential vulnerabilities.
See **SECURITY.md** for the responsible disclosure process.
